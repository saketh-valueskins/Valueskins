# Types of ValueSkins

## Type 1 — Brand Profile Skin
Attached to the brand's profile only. Acts as a UI sticker so content creators know what kind of brand they are looking at.

**Example:** Type 2 (creator) includes *Comedian*, but Type 1 (brand) includes *Comedy Club*.

## Type 2 — Campaign Targeting Skin
The skin a brand selects when creating a campaign. This asks the brand:
> "Creators having which skin would you like to choose to work with?"

## Type 3 — Creator Skin
Skins that creators hold. Two jobs:
1. Display which kind of creator they are
2. Let brands choose which creators they want to hire

## Invariant
**Type 2 and Type 3 must always share the same list.** If they diverge, brands could try to hire creators with a skin that doesn't exist in the creator pool.

**Type 1 has a different list** — Type 2 & 3 are about creators and professions, while Type 1 is about brands.
